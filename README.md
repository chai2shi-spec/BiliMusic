# BiliMusic

> 一款基于 **HarmonyOS** 的 B 站第三方音乐播放器，默认以**匿名 + buvid** 身份访问 B 站音频资源，可选扫码 / 短信验证码登录解锁更高音质与云端能力，数据全部保存在设备本地。
>
> A third-party Bilibili music player built natively for HarmonyOS — anonymous access by default, optional QR-code / SMS login for higher audio quality and cloud features, all data stored locally on device.

## 简介

BiliMusic 把 B 站上的音频内容（单曲、合集、音乐中心榜单、UP 主投稿、收藏夹）整理成一个纯粹的「听歌」应用。  
它**默认无需登录**，用匿名身份 + buvid 拉取音源；也可以在设置页**扫码或短信验证码登录** B 站账号
（凭据仅存本机），解锁大会员杜比 / Hi-Res 音质档，并开启**收藏夹同步、观看历史、我的关注**等云端能力。  
歌单、下载、播放记录始终只留在你自己的手机里。

- **作者**：chai
- **转译自**：[github.com/HanversionOvO/BiliMusic](https://github.com/HanversionOvO/BiliMusic)
- **运行环境**：HarmonyOS NEXT 7（API 26）手机 / 平板，适配折叠屏展开态与 md/lg 双栏布局

## 功能特性

### 🔍 搜索与发现

- **首页改版**：搜索框 + **快捷卡行** + **分类 chips**（推荐 / 排行榜 / 音乐中心）三段式布局，下拉刷新、上拉加载，骨架屏接管加载态
- **快捷卡行**：**最近播放卡**（封面即最近一首，播放键一键续播）+ **收藏歌单卡**（歌单「⋯」菜单「加入首页」自选，最多 9 张，播放键整单起播），上限 10 卡横滑
- **首页歌单卡增强**：长按菜单「移出首页 / 更换歌单」（原位替换）；订阅卡显示**「订阅」小标与 UP 投稿数**，口径与歌单页一致
- 搜索支持**「视频 / UP 主」切换**：搜 UP 命中 `bili_user`，显示头像 / 昵称 / **认证徽章** / 粉丝数，用于区分官方号与同名搬运号
- **首页三源缓存**：推荐 / 排行榜 / 音乐中心列表落盘缓存，启动先显缓存秒开再后台刷新，弱网 / 离线也能浏览
- 搜索覆盖**单曲、合集、视频、UP 主**等多种结果类型
- **搜索页视觉层次优化**：搜索框 / 历史与热门 / 结果分区层级收敛，间距与色彩语义统一，视觉主次更清晰
- 音乐中心支持真分页（`web/rank` / `comprehensive`），新歌榜自动补齐首屏

### 👤 账号（可选登录）

- **扫码登录**：B 站官方 passport 二维码流程，过期自动刷新
- **短信验证码登录**：手机号 + 极验滑块 + 短信验证码三步流程
- 登录凭据（SESSDATA 等）**只保存在本机**，不上传任何第三方服务器
- 登录后 playurl 自动带登录态，**大会员可解锁杜比 / Hi-Res 音质档**
- **大会员自动切无损**：登录成功检测到大会员身份时，自动把播放 / 下载音质切到杜比 / Hi-Res 档（可在设置页改回）
- 登录后额外能力：
  - **收藏夹同步**：B 站收藏夹 ⇄ 本地歌单镜像，**手动触发 + 按夹勾选 + 按夹「单向 / 双向」方向**——双向夹内本地加歌 / 移除**实时写回 B 站**（去抖合并、防风控限速、失败意图持久化补推；服务端取消收藏仅在夹完整拉取且无写回积压时才同步删除本地，防断网误删）
  - **观看历史与稍后再看**：拉取站内真实观看历史，条目一键播放，多 P 自动定位到上次看过的分 P
  - **我的关注**：已关注 UP 列表，直达 UP 主页
- 不登录可正常使用全部匿名功能，随时可退出登录并清除凭据

### 🎙️ UP 主生态

- **UP 主主页**：头像 / 昵称 / 粉丝数 / 签名 / **投稿总数** + **「投稿 / 合集 / 系列」三页签**浏览（投稿登录态 50 条/页，滚动自动翻页）；未订阅时头部一键「订阅」
- **合集 / 系列详情页**：从三页签点进，逐页加载（30 条/页，风控自动冷却重试），支持「播放全部」「保存为歌单」与单条「加入队列 / 下载」
- **主页内搜索投稿**：搜索框即时过滤已加载投稿（离线可用）；「搜索」走 B 站全站检索按 mid 过滤，可命中未加载页的投稿
- **投稿订阅**：订阅后新投稿**自动进本地订阅歌单**，按发布时间排序、超限丢最旧
- 歌单页 UP 订阅条目直接显示 **「N 个投稿」**（UP 投稿总数，不受单页拉取条数限制），行点击直达 UP 主页
- 曲目「⋯」菜单支持「进入 UP 主页」（搜索页与歌单详情页）
- 闭环体验：**搜 UP → 进主页 → 订阅 → 新歌自动进歌单**

### 📃 歌单与媒体库

- 收藏单曲、把**合集一键保存为歌单**
- 本地媒体库：自建歌单、增删曲目、**删除墓碑**（软删除，可追溯）
- **最近播放**记录（上限 100 条）
- **歌单管理**：长按**拖动排序**、**一键排序**（名称拼音 / 时长 / 播放量）、**多选合并**（预览去重、超限提示）、批量删除、**整单下载**
- **歌单去重**：自建歌单「去重」入口，同 id 精确重复 + 同名同歌手 / 时长差 ≤ 5s（或时长未知）的智能重复一并识别，确认后每组保留最靠前一首
- **跨平台歌单导入**：设置 → 歌单备份 → 从网易云 / QQ 音乐导入，粘贴歌单链接或歌曲列表文本，逐首搜索 B 站按相似度匹配评分，未决条目可跳过
- **歌单导出 / 导入**：剪贴板 JSON 方案，导出自动剥除本机路径，导入侧 id 去重、重名加后缀、畸形条目跳过

### ⬇️ 下载管理

- **音质选择**：64K / 132K / 192K / 杜比 / Hi-Res，按投稿实际档位优雅降级
- **串行下载队列**（每首间隔 350ms 防限流）+ 实时速度显示
- **断点续传**：基于 HTTP `Range` 续传，暂停后带 `ignoreWifiLimit` 重试
- **单条暂停 / 继续**：点击下载中 / 排队中的行即暂停（断点保留），点击已暂停的行继续
- **整单下载**：歌单「⋮」菜单一键批量入队，下载页按**歌单卡片归组**（「歌单」徽标 + 聚合进度，可展开查看每首进度）
- **失败重试**：失败行「↻」按钮 / 整行点击 / 多选「重试选中」三层入口
- **分组拖动排序**：下载页长按拖动歌单分组**整组重排**（自带浮起 / 让位动画），下载先后即时跟随；拖过的列表停止自动重排、新组仍置顶
- **音频导出**：已下载音频经系统保存对话框（`AudioViewPicker`）导出到文件管理器，扩展名按实际音质档派生（flac / mp3 / m4a），支持批量
- **保存到公共下载**：开关开启后（用户手势内授权）下载完成的音频自动搬移到系统「下载」目录（`Download/包名/`），文件管理器立即可见，单份存储不占双份空间；支持「同步已完成歌曲」批量搬移存量
- **听后缓存**：歌曲**自然听完**自动整首缓存（切歌 / 快进不缓存），与下载管理完全独立；512MB LRU（按 mtime 淘汰到 90% 水位线），流量门控跟随「仅 Wi-Fi 下载」，设置页开关 + 一键清理
- **仅 Wi-Fi 下载**开关，非 Wi-Fi 环境提示用户后放行
- **批量操作**：全部暂停 / 全部开始、**多选删除**
- **后台下载保活**：`DATA_TRANSFER` 长时任务，退后台 / 锁屏后队列继续跑

### ▶️ 播放

- **投播（AVCast）**：播放页顶栏投播按钮唤起系统投播设备选择器（`AVCastPicker`），选中后远端设备作为播放引擎出声（本机仅负责解析与控制，投播中本机静音），播放 / 暂停 / 进度 / 切歌随投播命令同步，断开自动恢复本机播放
- **沉浸取色背景** + 封面 **Swiper 双页**（封面 / Canvas 时间轴歌词）
- **封面风格三档**：唱片（圆形 20s/圈旋转，默认）/ 方卡极简（方形圆角不旋转）/ **全屏沉浸**——封面满屏宽顶状态栏，底部 `linearGradientBlur` 渐进模糊 + 取色主色溶解无缝衔接背景，展开随飞行渐显、收起柔退渐隐
- **收起动画三档**：柔退（内容层反向错峰淡出 + 背景面末端渐隐 + 封面 `geometryTransition` 回飞，默认）/ 柔退+竖向下拉跟手收起 / 下滑收起（整页加速下滑渐隐）
- **歌词服务**：**LX Music 多源链路**（酷狗 / 酷我 / 咪咕 / QQ / 网易云多平台聚合，支持**逐字歌词**平滑高亮）→ B 站标题清洗 → 候选评分 → 缓存 → 手动纠错（**手选结果单独缓存、优先于算法匹配**）；外部源全落空时（VOCALOID 原创、二创等曲库外歌曲）兜底读取视频 **CC / AI 字幕**当逐行歌词，时间轴与音轨天然对齐
- 唱片**旋转动画**（线性无限循环）与缓慢不规则**呼吸效果**
- **播放队列**弹层、循环模式：**顺序 / 单曲 / 列表循环 / 随机**
- **后台播放**（`KEEP_BACKGROUND_RUNNING` 长时任务保活）
- **蓝牙断开自动暂停**（音频路由监听 + toast 提示），**智能排除手表 / 手环**（设备名过滤 + 剩余蓝牙设备核查，连手表不误报「蓝牙已断开」）
- **播放状态恢复**：队列全量、当前曲目、播放进度、循环模式、随机开关、播放态双 JSON 文件落盘（进度 5s 节流），进程重启后完整恢复；配合「启动时自动播放」实现冷启动续播
- **响度均衡（实验性）**：读取 playurl 响度数据，播放时把偏响的歌自动衰减到统一响度（**只衰减不放大**，偏小的歌保持原样不抬底噪），记录随在线解析 / 下载累积，离线 / 缓存曲目同样命中，设置页开关默认关
- **切歌回听续播**：切歌后再回到之前的曲目，从上次听到的位置继续播放，进度不再丢失
- **首次播放淡入**：启动后首次播放音乐淡入出声，避免突然爆音
- **CDN 播放线路**：B 站 playurl 音频直链 upos 镜像 host 可替换（半优化 / 腾讯云 / Akamai 等），「自动」模式播放失败自动 Range 探测命中线路并持久化，也可在「播放设置 → 播放线路」手动指定，救活「能搜索、不能播放」的境外网络场景
- **分 P 视频**自动展开为多首曲目（分 P 下载 id 严格隔离，修复多 P 下载串音 / 队列缺首问题）
- **倍速播放**：设置页开关开启后，播放页可选 **0.25x–3.0x 九档倍速**，切歌、重启均保持；关闭开关立即恢复 1.0x
- **进度条样式四档**：经典（系统 Slider）→ 流光渐变条 → 脉冲波点 → 律动频谱条，设置页点击循环切换、即时生效
- **「与其他应用同时播放」开关**：开启后激活 `AudioSession`（`CONCURRENCY_MIX_WITH_OTHERS`，与其他应用音频双向混音），关闭恢复系统默认焦点行为（默认关）
- **后台耗电优化**：退后台自动冻结唱片旋转 / 呼吸等动画、播放进度落盘节流（5s → 30s），回前台即时恢复
- **「去歌单页选」**：播放页菜单把当前曲目送进歌单页，点选歌单一键加入
- **功能栏自定义排序**：播放页功能行改**分页交互**（一页 4 个等宽槽位，左右滑动翻页），9 个功能项**长按拖动排序**、前 4 位为默认页（设置 → 播放设置 → 自定义功能栏）
- **限定播放进度**：按曲记录跳过片头 / 片尾秒数（播放页「限定播放进度」弹窗两条独立调整条 + 秒数输入），在线 / 下载 / 队列 / 最近播放重放共用一份记录，重启不丢
- **定时停止播放胶囊**：播放页功能行快速入口——未开启时闹钟图标 0 分钟 ~ 2 小时档位菜单，开启后变倒计时文字片、每秒走字，可改档 / 关闭

### 🖼️ 桌面服务卡片

- **音乐播控卡片**（2x2 / 2x4）：封面 + 曲目信息 + 收藏 + 上一首 / 播放暂停 / 下一首；2x2 点播放触发黑胶溢出动效（liveForm 视觉区放大动画）

## 构建与运行

### 前置条件

- [DevEco Studio](https://developer.huawei.com/consumer/cn/deveco-studio/)（含 HarmonyOS SDK）
- 一台 HarmonyOS NEXT 7 手机 / 平板（或模拟器）

### 用 DevEco Studio

1. `Git Clone` 本仓库并在 DevEco 中打开 `HarmonyOS-Phone` 目录
2. 等待 `oh-package` 依赖同步完成
3. `Build → Build Hap(s) / APP(s)` 生成 HAP
4. **真机安装需在 `Project Structure → Signing Configs` 配置签名**（未签名只能产出 `entry-default-unsigned.hap`）

### 命令行（Hvigor）

```bash
cd HarmonyOS-Phone
hvigorw assembleHap --mode module -p product=default --no-daemon
```

> 注：命令行产物默认未签名，真机安装仍需在 DevEco 中配置签名。

## 使用说明

- **首次进入**会自动获取 `buvid`（防 412 必需），无需任何账号操作
- **搜索 → 点单曲 / 合集 / UP 主**即可加入播放或下载；搜到 UP 可进主页**订阅投稿**
- **登录**（可选）：设置 → 账户，扫码或短信验证码登录后开启收藏夹同步 / 观看历史 / 我的关注
- **下载页**顶部可切换「选择模式」进行批量管理、重试与删除；点击下载中 / 已暂停的行可单条暂停 / 继续；**长按拖动分组**调整下载先后
- **设置页**（分组入口 → 外观 / 播放 / 下载与存储 / 歌单备份二级页）可配置：账户、主题色（8 色）、定时停止播放、播放倍速、进度条样式、封面 / 收起动画风格、条目展示（长条 / 大封面双列）、响度均衡、与其他应用同时播放、应用图标、仅 Wi-Fi 下载、保存到公共下载、听后缓存、下载音质、缓存清理、歌单导出 / 导入等
- **查看更新日志**：设置页「查看更新日志」入口点按即弹窗查看历次版本更新内容
- **播放日志**：设置 → 日志记录，播放内核错误 / 降档 / 切换备用链等环形留痕（200 条）**并落盘持久化（跨重启保留）**，可整页或单条复制反馈问题
- **从网易云 / QQ 音乐导入歌单**：设置 → 歌单备份 → 从网易云 / QQ 音乐导入，粘贴链接或歌曲列表即可自动匹配 B 站音源建单
- **关于页**点「反馈Q群」一键复制群号；**打赏作者**二维码在设置页「打赏作者」
- 歌词、播放队列、循环模式均在**播放页**内操作；**投播**按钮位于播放页顶栏右侧

## 音质说明

音质档位与 B 站投稿实际编码绑定。当用户选择的档位不存在时，  
播放器会按既定优先级**自动降级到可获取的最高可用档**（例如选了 132K 但投稿只有 64K/192K，则退到 192K），  
界面显示的码率来自**实测带宽**而非档位标签，避免「显示 192kbps 实则 64K」的误导。
