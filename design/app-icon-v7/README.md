# app-icon-v7 · 粉底电视字标（alt_icon_17 / pink_tv_logo）

- 来源：用户提供的设计稿（`src.jpg`，微信图片 2026-11-17，1920×1920 JPEG）。
- 需求：**图案内容 0 改动，只处理边缘** —— 不删元素（天线 / 电视轮廓 / 白色
  字标全部保留），把四周做成满幅可被系统遮罩裁切的连续粉底。
- 2026-11-17 加入「应用图标设置」第六组。

## 源图边缘构成（实测）

设计稿是一枚粉色超椭圆（squircle）居中放在黑底上，边界有三层：

1. 图案内部的粉色带轻微渐变与边缘暗晕；
2. 图案外沿一圈**去饱和粉灰混合带**（如 `(201,118,148)`，max ≥ 170 ——
   按亮度阈值会被误判成「图案内」，v1–v5 版残留灰弧线 / 灰边即此原因）；
3. 混合带外一条**灰色描边**（max < 170）+ 四周**黑边距**（约 10–20px）。

## 处理算法（FullFrame6.java，DevEco JBR java 直接跑）

- 「饱和粉」判定图案真实外沿：`max ≥ 235 && (max−min) ≥ 110`
  （白字 spread≈0、混合带 spread≈83 都不会误判；图案内最深粉
  `(255,74,131)` spread=181、最浅粉 spread≈128，均覆盖）。
- 按行 / 列取「饱和粉」极值，极值之外的整条边界带（混合带 + 灰描边 +
  黑边距）逐像素向画面中心射线取第一个饱和粉像素的颜色填充；
- 重涂区做两遍 7×7 盒式模糊抹平射线纹理；
- 输出满幅 1024×1024 不透明 PNG（`alt_icon_fg_17.png`），bg 层沿用
  `alt_icon_bg_pink` 占位，圆角由系统遮罩裁切 —— 同 14/15/16 满幅方案，
  **必须用满幅版，圆角版会两次裁切出白边**。

## 小尺寸结论

- 图案主体（电视轮廓 + 字标）占满幅约 80%，24px 下字标可辨、轮廓完整；
- 四角填色与原粉底连续，系统裁形后无黑角、无灰边、无白边。
