## 0. 边界与不改清单

**改什么**：只重排一级设置页的信息架构与视觉表达；二级页保持现状（本轮只提出「值回显」所需的数据接口，不动其布局）。

**明确不动**（工程既有定论，动一处会连锁翻车）：

| 不动的东西 | 原因 |
|---|---|
| `Index.HdsTabs` / `barFloatingStyle` / `PlayBar` / `components/player/*` | 用户历次明确要求不动；miniBar 受控样式的两段式动画事故 |
| `Index.tabTitleRow` 的 22fp「设置」标题 | 三页签共用、水平基线 16 已定版；本方案只在**右侧补副行**，不改标题本体 |
| `TopGradientBlurOverlay` + `TabScrollerHolder.settings` | 自绘顶栏模糊链路，逐帧命令式驱动，零重建 |
| 登录三态（未登录 / 已登录 / `loginStale`） | `SETTINGS.md`：失效只标 stale、不清凭据 |
| `HdsListItemCard` 在二级页的用法 | 二级页已落地，本轮不重做 |
| `LazyPageRegistry` 懒加载注册 | 路由名不变，避免连锁改动 |

**保留的资产**：`InsetCard`（bg_card / 圆角 12 / 左右 16 / `clip(true)`）、`CardDivider`（左缩进 16）、按压态 `press_overlay`、`SectionHeader` / `SectionFooter` 组件本身。

### 0.1 勘误（2026-11-09 23:07，务必按此实施）

初版方案把「收藏夹同步」和「华为云空间同步」写成「同一目标的两条路径」，**这是错的**。逐个 grep 路由后确认二者是**不同功能、不同页面、不同路由**：

| 一级/二级入口 | 路由 | 页面 | 依赖登录 | 结论 |
|---|---|---|---|---|
| 设置页账户卡「收藏夹同步」（`SettingsPage.ets:621-623`） | `CloudSync` | `FavSyncPage`（B 站收藏夹 → 本地歌单镜像，手动选择性同步） | 是，`if (this.loginUser !== null)` 才渲染 | **必须保留** |
| 「歌单导入」→ `PlaylistBackupPage.ets:540-551`「华为云空间同步」 | `HuaweiCloudSync` | `CloudSyncPage`（华为云空间自动同步歌单/拾音/最近播放） | 否 | 一级页缺直达入口 |

`CloudSyncPage.ets:4` 文件头也写明「`'CloudSync'` 已被 B 站收藏夹同步页占用」，`LazyPageRegistry.ets:94 / :159` 是两个独立 case。

**因此 D4 的真实症状是**：华为云空间同步被埋在「歌单导入」二级页第 3 组，一级页只有名字毫不相干的「歌单导入」，用户找不到；而账户卡那行「收藏夹同步」因词形相近容易被误认为就是它。修改时**绝不能删 `CloudSync` / `FavSyncPage` 这一行**，「命名去重」指的是给两者加消歧副标题、并在一级页补一条直达 `HuaweiCloudSync` 的入口，不是合并路由。

## 2. 八个诊断

### D1 · 12 个入口等权重、两张卡无语义（P0）
`build():650-741` 刻意不加 `SectionHeader`（注释理由：「根固定栏已常显设置」）。结果：用户看不出「播放设置」和「查看更新日志」为什么被分到两张卡，也看不出哪张更重要。**等权重 = 无优先级**，高频的「音质 / 网络 / 主题」和一年点一次的「打赏 / 邀测」并排同尺寸。

### D2 · 四类动作共用一种符号（P0）
17 个可点行里，「进二级页 / 原地弹窗 / 外链 / 复制」四种结果，14 行统一 `chevron_right`。点「PiLink 邀测」会离开 App、点「反馈Q群」什么页面都不进只复制 —— **点击前完全无法预判**。`AboutEntryRow` 与 `FeedbackEntryRow` 已各写一份变体，说明这个缺口是被临时补丁堵的，没有形成规则。

### D3 · 零状态回显（P0，最大可用性缺口）
12 个入口里只有「关于本项目」显示版本号，其余 **0 行显示当前值**。要知道「播放音质是哪档 / 仅 WiFi 开没开 / 主题是深色还是跟随系统 / 云同步上次何时成功」，必须点进二级页 —— 2 次点击换 1 个布尔值。二级页内部反而做得很完整（`SuffixText` 显示当前档），**信息在最外层被丢掉了**。

### D4 · 华为云空间同步入口埋得太深、且名称易混（P0，真实事故）
- 一级页叫「歌单导入」→ `PlaylistBackupPage`，而**华为云空间同步藏在该页第 3 组**（`:540-551`，路由 `HuaweiCloudSync`）。「歌单导入」这四个字完全不提示里面有云同步。
- 账户卡另有一行「收藏夹同步」（`:621-623`，路由 `CloudSync` → `FavSyncPage`），**是 B 站收藏夹镜像、且登录后才渲染**。它与华为云空间同步是两件事（§0.1），但都叫「…同步」，用户极易认错。
- 后果：未登录 / 只想同步本机数据的用户，在设置页完全找不到云同步；上一轮真机排查「设置页里没有云同步入口」正是这个症状。**修法是「补一条一级直达 + 给两行加消歧副标题」，不是删掉收藏夹同步、更不是合并两个路由。**

### D5 · 彩色图标系统与主题色脱节（P1）
`ICON_BG_*` 9 个常量（`:62-72`）是硬编码 iOS 系统色板，**不订阅 `STORE_THEME_*`**。用户把主题色切成「青 / 绿 / 紫」后，设置页图标依旧粉蓝紫绿灰，是全 App 唯一不跟随主题的一块。深色模式下 9 个高饱和实底块在 `#1E1E24` 卡面上形成「彩色糖块」噪音（真机截图可证），与整体克制的深色界面冲突。附带的 4/9 对比度不达标见 §1.5。

### D6 · 三处无障碍硬违规（P0，可一次修完）
`text_tertiary` 两种模式都没到 4.5:1；徽标 10fp 与脚注 12fp 越出六档字阶；账户动作胶囊 28vp 热区且紧贴整行热区（这正是 `UI-LAYOUT.md` 里「想点 ⋯ 却触发播放」的同类结构）。

### D7 · 末行被悬浮胶囊遮挡（P0，真机实证）
`contentEndOffset(160 + safeBottom)` 只保证「滚到底能看见」，不保证「首屏不遮」。当前 12 行刚好把最后一行压在胶囊下。

### D8 · 大屏单列浪费 + 无搜索（P2）
`constraintSize(maxWidth 840)`（`:770`）在平板横屏下把 16fp 文字拉成一行长条，右侧大片空白；工程已有 `TwoColumnLayout`，但设置页未用。≥50 项分散 6 页、零搜索，找「淡入淡出」这类低频项需要逐个二级页翻。

## 3. 设计目标

| # | 目标 | 可度量判据 |
|---|---|---|
| G1 | **可预判** | 每行点击结果由尾部符号区分；分组有标题 |
| G2 | **不点即知** | 高频入口首屏显示当前值，状态查询 0 次点击 |
| G3 | **直达** | 云同步、缓存清理从 2 次点击降到 1 次 |
| G4 | **一致 / 无障碍** | 图标跟随主题 token；AA 全达标；字阶六档；热区 ≥44vp |
| G5 | **首屏不被遮** | 静止态最后一行完整可见 |

**关键取舍：不把 50 项平铺回一级页。** 那会变成一张比现在更难扫的长列表。保留「一级概览 + 二级详情」两层，只重排一级、补值回显、把云同步提上来。

## 10. 红线（实施前逐条对照）

1. **带参 `@Builder` 按值传递** → 动态值不进参数，体内现算（§5.1）。
2. **受控组件用 `$$`** → 若折叠态用 `bindSheet` 类受控组件，必须双向绑定；纯 `if` 折叠不受此限。
3. **函数类型参数不能做状态变量** → 点击回调保持普通成员。
4. **不在 HDS 托管内容里用 `onAreaChange` 回写状态** —— 顶栏/迷你栏事故通用教训。
5. **`@Watch` 只在值真变时触发** → 「写回同一个值」的收尾要另配兜底刷新（设置页已有定时停止同款教训）。
6. **颜色一律 `$r('app.color.*')` / `STORE_THEME_*`**；符号名先查 `sysResource.js` 的 symbol 段（在 openharmony 侧，非 hms 侧）。
7. **`ListItem` 只能有 1 个直属子节点**；加折叠区时注意括号，报错行号会指向后面无关 `ListItem`。
8. **不删登录三态、不改 `isLoginStale` 语义**；`getBuvid()` / `CryptoUtil` 与登录无关，别顺手清。
9. **不改 `CONTENT_END_OFFSET`（四 Tab 共用）**；不改 `barFloatingStyle` / `PlayBar` / 播放页全家桶。
10. **二级页本轮不动**；方案里提到的值回显只读，不写二级页状态。
11. **不删「B 站收藏夹同步」、不合并 `CloudSync` / `HuaweiCloudSync` 两个路由**（§0.1）；折叠的登录后 4 行原样保留，只补副标题消歧。
12. **不改 `resources/*/element/color.json` 里的 `text_tertiary`**（决策 3）；设置页内一律就地换 `text_secondary`，全站 token 另立任务。
