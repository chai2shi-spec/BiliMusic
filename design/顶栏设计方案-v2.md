# BiliMusic 顶栏设计方案 v2

> 2026-10-22 定稿。范围：根栏 HdsNavigation（首页 / 歌单 / 下载 / 设置）+ 全部 11 个子页（HdsNavDestination.titleBar）。
> 本文只描述规范与差距，**不包含代码改动**；落地按第 10 节清单分批执行。
> 关联实现：`utils/NavTitleStyle.ets`（尺寸令牌）、`components/NavTitleRow.ets`（子页标题行）、`utils/HdsTitleBarStyle.ets`（材质与滚动联动）。

## 2. 设计原则

1. **一层材质**。只有标题行（56vp）承载 HDS 材质与滚动模糊。标题行内的内容件、辅助行、多选工具条**一律不得自带底色**，否则会截断沉浸光感，形成硬边。
2. **一条竖线**。标题、搜索框、页签胶囊、列表首项共用 `NAV_H_PADDING = 16` 左缘，全站不出现第二套水平基线。
3. **一档参数**。同一层级的模糊区间必须一致；跨页转场时顶栏不能出现「这页一滚就起糊、那页要滚很久」的观感断层。
4. **模板复用**。顶栏只允许 6 种形态（第 4 节），新页面必须归属其中一种，不允许新增自绘栏。

## 3. 结构分层

自上而下四段：

| 层 | 高度 | 承载 | 说明 |
|---|---|---|---|
| L0 状态栏 | safeTop | HDS `avoidLayoutSafeArea` | 材质自动延伸到底，页面不参与 |
| L1 标题行 | 56 | `titleBar.stackBuilder` | 唯一带材质层；内容垂直居中 |
| L2 辅助行 | 44（可选） | `position({ x: 0, y: 56 })` 溢出渲染 | 页签胶囊 / 多选工具条，无背板 |
| L3 内容 | — | 页面 List / Scroll | 首项让位 = safeTop + 56 + 辅助行高 |

容器约束（不可省）：外层 `Stack` 需 `clip(false)`（否则 L2 被裁掉）+ `hitTestBehavior(HitTestMode.Transparent)`（L2 未覆盖的空白区点击穿透到列表）。

## 6. 材质与滚动联动

单源：所有页面（根栏 + 子页）从 `HdsTitleBarStyle.styleOptions(startVp, endVp)` 取 `TitleBarStyleOptions`，不得内联。

定版参数：

| 项 | 值 | 理由 |
|---|---|---|
| `materialType` | `ADAPTIVE` | 跟随系统策略；`IMMERSIVE` 在部分机型无光感 |
| `materialLevel` | `SMOOTH` | 成本/质感平衡点；低端机若掉档回退 `GENTLE` |
| `blurStrategy` | `ENABLE` | 默认 `ADAPTIVE` 下动态模糊可能不渲染，必须强制开 |
| `thermoCtrl` | `false` | 置 `true` = 主动申请「发热降级」，是连续播放后材质消失的隐性来源 |
| `scrollEffectType` | `GRADIENT_BLUR` | 渐变模糊；`COMMON_BLUR` 为快滑闪烁的退路 |
| `originalStyle` / `scrollEffectStyle` | 透明 | 让系统模糊与材质透出 |

三条禁忌（都踩过）：

1. `MaterialLevel` 的 `EXQUISITE = 0`，**不能用真值判断**档位（`if (level)` 会把 EXQUISITE 判成未设置）。
2. `titleBar({ style })` 按**对象引用**判等。每次 new 一个对象 → HDS 认为样式变了 → 销毁重建材质层 → 肉眼一帧空白。必须走内容键缓存（`gb|start|end|immersive`）。
3. 顶栏内容件禁止 `.backgroundColor`；`bottomBuilder` 区同理。

## 7. 交互规范

**返回键**（2026-10-24 整改：自绘键移除，改用 HDS 默认键）
- HDS 默认返回键（"<" 系统样式）：`stackBuilder` 不再自绘返回键、各页不设 `hideBackButton(true)`，由 HdsNavDestination 渲染并管理位置，正确避开状态栏。
- 背景：`avoidLayoutSafeArea` 下自绘键顶入状态栏（用户反馈），且 2026-10-22 双键重叠的根源即自绘键存在；移除后默认键恢复显示，单键成立。
- 无障碍标注由 HDS 内建；`NavTitleRow` 行首保留 48vp 定宽占位，标题左缘稳定在 x=64。

**标题**
- 20fp / Bold / 单行 / 超长 ellipsis。
- 可用宽度 = 屏宽 − 16×2 − 44 − 4 − 右侧动作区；T2 有动作时标题先让位，不允许截断动作文字。

**文字动作按钮（T2）**
- 13fp / 高 32；命中区需用 `responseRegion` 补到 44 高（当前 32 高、水平 padding 12，纵向不达标）。
- 一页最多 2 个；主操作（新建 / 全部开始）用品牌粉，次操作（选择 / 暂停）用次级文字色。
- 按钮文案不做动态增减以外的形态变化（避免「选择 ↔ 完成」宽度跳动带动标题位移，可用固定最小宽度吸收）。

**多选工具条（L2）**
- 高 44，左右内边距 **16**（现状歌单页 20/12、下载页 16/16，需统一）。
- 左侧放全选/取消全选，右侧放破坏性动作（删除）,中间留空；选中计数写进文案：`删除选中(3)`。
- 出现/消失：高度 44 与整页内容让位量必须同时变化，否则列表首项会被工具条压住。

**页签胶囊（T1 / T6）**
- 胶囊高 32，行高 44，行内垂直居中；选中态由 HDS 托管，不自绘指示条。

## 8. 自适应与边界

| 场景 | 处理 |
|---|---|
| 折叠屏 / 平板（md） | 顶栏内容经 `immersiveTitleBarNarrow` 收窄到 `contentMaxWidth`（600），与内容列同宽；两侧空白 `hitTestBehavior(Transparent)` 穿透 |
| 横屏 / 分屏 | 同一套收窄逻辑，不额外写断点分支 |
| 长标题 | ellipsis；T4 不做跑马灯 |
| 系统大字体 | 56 可容纳 20fp×1.75 ≈ 35；L2 建议由固定 `height(44)` 改 `constraintSize({ minHeight: 44 })`，防 13fp 放大后胶囊压边 |
| 深色模式 | 文字 `text_primary`、按压 `press_overlay`、兜底玻璃 `header_glass_tint*` 全部走资源，不写死色值 |
| 底部胶囊一致性 | 迷你栏 / 导航栏用 `barFloatingStyle` 的同套路（内容键缓存 + 同档材质），顶栏改动后需回归一次底部观感 |

## 9. 观感验收标准（真机）

1. 首页慢速下拉 0→200vp：渐变模糊平滑起糊，无硬边、无「闪一下消失」。
2. 首页快速 fling：模糊不中断；停下后停在完全态。
3. 一级 → 子页转场：顶栏材质不清空、不重建（`hilog | grep TopBar` 只应在真正换样式时出一条）。
4. 子页一进入即轻微滚动：立即起糊（不应出现「滚了 30vp 还是全透明、标题与内容文字重叠」）。
5. 三页签来回切换：标题与搜索框左缘始终同一条竖线。
6. 折叠屏开合：顶栏内容与内容列同宽，不出现错位。

## 11. 待决策点

**A. 模糊区间分档还是一刀切？**
- 方案 A1（推荐）：T1–T4/T6 用 0→8，T5 两页保留 30→80。依据：T5 的 `bottomBuilder` 头部区属于顶栏延伸，滚过头部才进完全态符合「头部大字 → 顶栏接管」的阅读顺序。
- 方案 A2：全站 0→8，最简洁，但 T5 会在大字还在屏幕中央时就起糊。

**B. T5 是否补「滚动淡入标题」？**
- 现状滚过头部后顶栏只剩返回键，用户在中段失去位置感。
- 建议做：滚动量超过头部区高度 × 0.6 时，标题以 200ms 淡入 + 轻微上移 4vp；回到 0 时淡出。需新增一个滚动量状态（用 `onDidScroll` 或现有 `onAreaChange` 回写高度即可）。

**C. 搜索页页签行是否并入 44 体系？**
- 并入后全站辅助行只此一档，但页签行视觉会紧 5.6vp（胶囊上下留白从 17.6/8 收到 6/6）。
